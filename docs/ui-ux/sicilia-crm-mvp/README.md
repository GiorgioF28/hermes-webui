# Sicilia CRM browser evidence

Screenshots were captured with a temporary localhost static-file harness and
mocked CRM HTTP responses. They show synthetic records only; the harness was
shut down at the end of capture. No Hermes server, provider, GPS sensor, or live
customer data was used. OpenStreetMap tiles were loaded for the visible Sicily
viewport and are attributed in the page.

Viewport screenshots: 1200 px desktop, 650 px narrow, and 360 px mobile. Each
set includes the map, record form, and AI draft dialog. The desktop saved view
shows the synthetic draft-save-readback flow.
